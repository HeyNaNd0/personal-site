# ericops.cloud

Personal portfolio site for Eric Fernandez — Cloud Infrastructure Engineer & Kubernetes Specialist.

**Live:** [https://ericops.cloud](https://ericops.cloud)

## About

Single-page portfolio built with React + Vite, featuring:

- **About** — background, skills, and tech stack
- **Experience** — interactive accordion of roles at Microsoft, Google, and Meta
- **Projects** — AKS AI Agent, LLM InferenceOps, ARO SME Roadmap Dashboard
- **Blog** — technical writing and notes
- **Contact** — email, LinkedIn, GitHub links

## Stack

- React 19
- Vite 6
- Hosted on Azure Static Web Apps (Free tier)
- Auto-deployed via GitHub Actions on push to `main`

## Local Development

```bash
npm install
npx vite
```

Open `http://localhost:5173`

## Deployment

Every push to `main` triggers a GitHub Actions workflow that builds and deploys to Azure Static Web Apps automatically.
